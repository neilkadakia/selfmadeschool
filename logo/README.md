# Self Made School: Dawn Sweep logo assets

The locked mark: SELF-MADE in cream, SCHOOL in growth-green, a small green hyphen,
and one round-cap underline stroke sweeping amber → green (the sunrise).

## Spec
- Type: Bricolage Grotesque 800, letter-spacing -0.03em, all caps
  https://fonts.google.com/specimen/Bricolage+Grotesque
- Hyphen: 0.62em, vertical-align 0.1em, green
- Underline path (viewBox 0 0 300 20): M6,15 C90,4 230,4 294,11; round caps, never redrawn
- Dawn gradient stops: #F5A83C -> #B8C94F (55%) -> #43DE7B, left to right
- Colors: ink #0E0E12 · cream #F2EEE3 · green #43DE7B (on paper: #2BB35C) · amber #F5A83C

## Files
- wordmark-source-on-ink.svg / wordmark-source-on-paper.svg: EDITABLE masters, live text
  (install Bricolage Grotesque, or open in a browser online; convert text to outlines in
  Illustrator/Figma before sending anywhere fonts are not guaranteed)
- wordmark-on-ink.png / wordmark-on-paper.png (2x) and -4x versions: exact renders
- mono-on-ink.png / mono-on-paper.png: one-color fallbacks (stroke takes the type color)
- avatar.png / avatar-4x.png: SMS monogram circle avatar (16b: full-bleed letters, final S green, dawn sweep)
- self-made-school-icon.svg: icon source (16b monogram; LIVE TEXT, needs Bricolage Grotesque; ship the PNGs, not this)
- icon-512/192/64/32.png: raster favicon/app-icon sizes (use these everywhere; repo gets app/icon.png)

## Rules
- Clear space: one cap-height of S on all sides
- Minimum width 140px; below that use the icon/stroke alone
- On-brand: dawn gradient stroke, green hyphen + SCHOOL. One-color contexts: everything takes the type color, never a third color
- The wordmark never stacks; the SMS monogram (16b) is the only compact mark: avatar AND favicon
- Never straighten or thicken the stroke
