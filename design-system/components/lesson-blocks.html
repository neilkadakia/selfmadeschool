Lesson Blocks

Split, Steps, Drawings

The three block kinds that keep a written unit from being a wall of prose. They carry structure, never bytes: a drawing is picked by name from a fixed set the site knows how to make, so a lesson stays a plain object the API and the phone app can both read. Words inside a picture are always real text, because a 600-unit viewBox squeezed onto a phone turns 15px type into 8px.

split

The same moment in two voices, line by line. Two columns on a desktop; on a phone the header drops away, each row stacks, and every cell grows its own tiny label so a pair can never come apart.

steps

A numbered flow. The spine is drawn from each number down to the next, so the last step ends the line rather than trailing off.

The three-line answer

  1. 1Catch itNotice the verdict as a verdict. "There's the critic." Naming it breaks the trance.
  2. 2Get specificReplace the verdict with what actually happened, in one sentence, with no adjectives.
  3. 3Call the next playSay the next physical action, small enough to do today. The critic cannot argue with a scheduled action.
